# 《界外》（暂定名）

一款以调查、推理、时间循环和认知恐怖为核心的互动文字游戏。

> 一支中国联合科考队循着一段不可能存在的中文求救信号，进入中蒙边境一座已从地图上抹除的废弃武器试验场。随着时间不断回到进入禁区的当天，他们发现求救者不是失踪的苏联考察队，也不是当年的实验幸存者，而是尚未经历这一切的他们自己。

## 项目定位

本作希望向《R-Point》所代表的孤立禁区、队伍失序、身份怀疑与历史幽灵致敬，并结合封闭因果循环、多版本自我和“试图阻止事件反而促成事件”的时间结构，建立一套原创的边境历史恐怖故事。

游戏的核心不是战斗，也不是寻找一个可以被消灭的鬼，而是：

- 利用上一轮获得的信息改变下一轮行动；
- 从互相矛盾的记录、证词和物证中重建真相；
- 判断身边的人属于哪一段历史、哪一次循环；
- 发现玩家自己也是恐怖事件因果链的一部分。

三条核心设计支柱：

1. 信息比武器更重要；
2. 每次循环都重新解释旧事件；
3. 世界在循环，但故事和玩家的责任始终向前。

## 故事舞台

故事发生在中蒙边境附近一片完全虚构的荒漠无人区。这里没有对应的真实军事设施或真实坐标。

区域暂定名为：

```text
北垣试验场
现代档案代号：B-17
蒙古旧称：哈日乌拉禁地（暂定）
苏联档案编号：Объект 17（暂定）
日方档案代号：特号界域（暂定）
```

试验场并不是一个单一时期的遗址。不同年代的设施覆盖、侵入并改造了同一片区域：

```text
现代科考营地
    ↓
废弃观测站
    ↓
苏联地下调查设施
    ↓
日本时期实验区
    ↓
被建筑掩埋的古代禁地与隔离遗址
```

在不同循环中，同一地点可能显露出不同历史时期的状态。第一轮看见的观测站，下一轮可能露出墙后的苏联文字；再次进入时，它也可能短暂恢复为战争时期的实验室。

## 四层历史

### 古代禁地

在所有现代设施出现以前，这里已经是一处不为外界所知的禁地。

古代守护者并非崇拜盘踞于此的邪恶存在，而是在观察、记录并限制一种无法用当时知识解释的异常现象：人的记忆能够越过时间边界；同一个人可能留下多个版本；死者最后的认知会在环境中反复出现；被异常完整“记住”的人，可能逐渐被另一个版本取代。

后世所称的仪式、禁忌和宗教建筑，本质上是一套以古代语言建立的隔离体系。故事不会把任何现实蒙古族群或现实宗教描述为邪恶来源。

### 日本时期实验

战争时期，日方从地方传闻与残缺记录中发现这片区域，并在遗址之上建立秘密实验区。

研究者试图将异常用于审讯、记忆提取、战场预知、意识同步，以及让死亡前的信息向过去传递。为此，大量战俘、平民和被强迫参与者遭受了制度化的人体实验。

日方并没有创造异常，但他们的实验放大了它，并破坏了古代隔离结构。这里的暴行将作为历史罪恶及故事因果的一部分呈现，不作为猎奇奇观。

### 苏联考察

冷战时期，苏联方面通过战争遗留档案和异常无线电记录发现试验场，以地质与辐射调查为掩护派出考察队。

他们发现了一批日期来自未来的调查文件，也发现自己的人员名单每天都在变化。考察队随后集体失踪，但他们并非在同一天、同一次循环中死亡。部分成员可能被困在不同的时间层中，经历了远超现实时间的主观岁月。

玩家在探索中可能遇见同一名调查员的不同状态：年轻、衰老、友善、敌对，甚至已经知道玩家下一步会说什么。

### 现代联合科考队

现代中国联合科考队收到了一段从禁区内持续传出的中文求救信号：

> 这里是联合科考队。人员七名。不要回应我们的呼号。不要让第八个人进入营地。

信号记录的发送时间来自三天后，呼号却属于尚未出发的玩家队伍。

档案显示科考队共有七人。但抵达试验场后，每个人都自然地记得队伍一直有八个人。第八人拥有完整装备，知道所有人的姓名，也能说出共同经历；唯独出发记录、照片和外界通信中没有他的存在。

## 玩家身份

玩家是科考队中的地球物理与遥感数据工程师，同时负责现场数据、无线电记录和调查时间线。

玩家不是战斗专家。其主要能力是：

- 操作通信与观测设备；
- 比对地图、时间和历史档案；
- 记录队员位置、证词与状态；
- 在循环后利用已经掌握的知识提前行动；
- 识别不同循环之间不应存在的差异。

玩家与这片区域还存在一项暂未公开的私人联系：多年前，一名参与外围调查的亲属在附近失踪，而这次求救信号中出现了他的声音。

## 科考队与“第八人”

正式角色暂定为：

- 队长：负责行动决策，但隐瞒任务的真实来源；
- 历史学者：能够阅读日方与苏联档案；
- 蒙古族考古学者：理解遗址传统，并反对将其简单解释为迷信；
- 医疗人员：最先发现队员身上存在不属于本轮的伤口；
- 通信工程师：坚持自己从未发送过求救信号；
- 安保队员：具备危险环境行动能力，也最容易成为怀疑对象；
- 玩家：负责数据、时间线和调查记录；
- 第八人：所有人都认识，但没有任何出发记录。

第八人不被预设为传统意义上的鬼。他可能是上一轮被遗留的队员、来自未来的某个人，也可能是试验场从集体记忆中制造出的替代者。其最终身份将在正式因果时间线中锁定。

## 异常与时间循环

本作采用“固定时间闭环、局部多版本重叠、历史残响”的循环模型。

一次循环从科考队越过边境旧界碑开始，到试验场在凌晨重新启动结束。基础规则暂定如下：

1. 玩家意识和部分记忆可以进入下一轮；
2. 普通世界状态和物品会恢复到循环基线；
3. 被放入特殊锚点的物品可能跨越循环保留；
4. 死亡、暴力和强烈情绪会留下声音、文字或行为残响；
5. 某些循环中，上一轮的人仍会继续活动一段时间；
6. 同一个人的多个版本接近时，现实会加速失稳；
7. 初始求救信号最终必须由某一轮中的玩家或队员发出；
8. 玩家若拒绝发送信号，最初的科考队便不会进入试验场；
9. 但如果科考队从未来过，就不会有人作出拒绝发送信号的决定。

循环中的规律分为三层：

- 核心不变量：永远不会改变，是玩家推理的基础；
- 条件变量：只有在明确条件被改变时才变化；
- 表象异常：看似破坏规则，实际存在可调查的原因。

规律可以被玩家误解，但不能被故事任意修改。每项异常都必须拥有来源、征兆、作用范围和最终解释。

## 恐怖来源

这里没有一个等待玩家消灭的单一怪物。

试验场会保存人在死亡、恐惧和绝望中最强烈的认知，并让后来者逐渐把这些残留认知当成自己的记忆。古代守护者的戒惧、实验受害者的痛苦、研究人员控制未来的执念、苏联调查队的猜疑，以及现代科考队每次失败留下的记忆，共同构成了此地的异常。

真正的怪物是这片区域保存下来的全部恐惧。它正在利用玩家一次次拯救同伴的愿望完成自我复制。

本作主要通过以下方式制造恐怖：

- 人数、姓名、身份与共同记忆不一致；
- 同一段文字在下一轮只改变一个词；
- 玩家提前知道事件，却不知道自己是否正是事件的原因；
- 已经死亡的人重新出现，并害怕自己上一轮的死亡地点；
- 玩家发现神秘警告、敲门声或袭击来自另一个循环中的自己；
- 越接近真相，可信的记录越少，而玩家必须承担的责任越大。

## 核心悬念

故事将围绕以下问题逐步展开：

1. 第八个人究竟是谁，他属于哪一次循环？
2. 求救信号最终由谁发送，为什么警告不要回应？
3. 古代隔离体系真正限制的是什么？
4. 日方实验究竟放大了什么现象？
5. 苏联考察队为何在不同时间层中失踪？
6. 玩家失踪的亲属是否真的存在，还是被植入的记忆？
7. 玩家必须重复哪一项残忍行为，才能维持最初的因果闭环？
8. 逃出试验场和终止循环，是否只能完成其中一个？

## 可能的结局方向

结局不通过最后一次选择直接决定，而由玩家历次循环中的知识、行为、牺牲、异常程度和角色命运共同解析。

暂定方向包括：

- 玩家离开试验场，但求救信号仍在呼叫下一支队伍；
- 玩家终止循环，却必须让某名队员永远留在其中；
- 玩家取代第八人的位置，成为下一轮所有人都认识的陌生人；
- 玩家发现自己是最初异常事件或求救信号的制造者；
- 玩家拒绝维持闭环，使现实产生无法预测的新分支。

## 创作边界

本作可以致敬孤立禁区、人员名单异常、不可靠记忆、多时代遗迹和无线电幽灵等恐怖母题，但不会复用任何作品的具体人物、地点、鬼怪形象、死亡顺序、标志性台词或最终答案。

为保持原创性，本作的核心问题不是“队伍里谁已经死了”，而是：

> 队伍里的这个人，究竟属于哪一次循环、哪一段历史？

涉及现实历史、民族、宗教与战争罪行的内容将在后续创作中进行资料核查。所有超自然组织、试验场、档案编号、仪式和具体事件均采用虚构设定，避免将现实民族或宗教作为恐怖与邪恶的来源。
